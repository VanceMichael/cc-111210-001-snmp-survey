# 管理网关协议
网关已负责 SNMP 编解码，HTTP 返回保留原始 OID 与值。`/bulk?after=<oid>&limit=2` 返回词典序后继，最大三格；可跨列边界。三个列根的含义依次为接口名称、无符号计数器、位宽，索引为站区与接口的复合后缀。
`/restart` 改变启动纪元，`/topology` 增加一个接口。不同列可以缺项，HTTP 成功不代表整表完成。单次查看不会跨列组装，也不计算采样差值。

## 演练端点
`/tick?amount=N` 按位宽推进计数器，可演示回绕。`/topology` 默认只给名称列新增接口 3.1；`full=1` 三列同时新增，`mode=remove&suffix=<后缀>` 移除接口，`afterCalls=N` 延迟到第 N 次 `/bulk` 后生效。`/restart?afterCalls=N` 同样可延迟生效。`/flap?every=N` 让每第 N 次 `/bulk` 改变启动纪元，`every=0` 关闭，用于演练持续不稳定。

## 采集语义
整表采集为每个列根维护独立的词典序游标，只消费列根下的单元格；返回落入相邻子树时结束该列，不拼接入表。行身份取完整 OID 后缀，复合索引不拆分。任何列的行集合与并集不一致时，全部列重读一次，以区分稳定缺失与扫描期间的拓扑变化；重读与重启重试均有边界，超出即返回明确的不完整原因。扫描状态在列边界落盘，进程停止后可续采；暂停期间设备重启则丢弃旧进度，不混用两次启动的数据。两轮清单按后缀对齐稳定接口，计数器差值按位宽修正回绕，跨重启时差值置空。
